# 💕 Entre Nós

Um cantinho feito para casais se divertirem, compartilharem desejos e se conhecerem melhor, uma pergunta de cada vez.

## ✨ Funcionalidades

- 🃏 Perguntas em cartões, com categorias fofas, provocantes, de intimidade, desejos e muito mais.
- 🎲 Escolha uma categoria ou jogue com todas.
- 💬 Respostas compartilhadas em tempo real entre os dois participantes.
- 💌 Sala para o casal, com convite por link.
- 📝 Histórico das perguntas e respostas.
- ⚙️ Gerenciamento de perguntas pelo criador da sala.
- 🌙 Modo escuro e modo claro.
- 📱 Interface responsiva para computadores e celulares.
- 🔐 Contas individuais com e-mail e senha.

## 🛠️ Tecnologias

React, TypeScript e Vite, com Firebase Authentication para as contas e Cloud Firestore para armazenar e sincronizar os dados. Hospedagem no GitHub Pages.

## 💖 Como jogar

1. Crie sua conta e entre no site.
2. Crie uma sala e envie o convite para seu amor.
3. Cada pessoa entra com sua própria conta.
4. Escolham uma categoria, respondam aos cartões e descubram mais um sobre o outro!
